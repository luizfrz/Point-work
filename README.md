# Point Work

Sistema simples para registro e gerenciamento de ponto eletrônico.

## Funcionalidades

* Cadastro de usuários
* Registro de ponto (Entrada, Pausa e Saída)
* Visualização gráfica dos registros
* Limpeza do histórico de registros
* Interface web intuitiva

## Tecnologias Utilizadas

* JavaScript
* HTML5
* CSS3
* Yarn

## Instalação

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/point-work.git
```

Acesse o diretório do projeto:

```bash
cd point-work
```

Instale as dependências:

```bash
yarn install
```

## Executando o Projeto

```bash
yarn start
```

Ou utilize o comando configurado no arquivo `package.json`.

## Estrutura do Sistema

* **Entrada:** Registro do início da jornada.
* **Pausa:** Registro de intervalos durante a jornada.
* **Saída:** Registro do encerramento da jornada.

## Objetivo

O Point Work foi desenvolvido para facilitar o controle de jornada de trabalho, permitindo registrar horários e acompanhar os apontamentos de forma simples e organizada.
